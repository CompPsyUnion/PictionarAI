# Picture This — local event quiz

Open `index.html` in a modern desktop browser such as Chrome or Edge. No installation, server, account or internet connection is required.

## Set up the event

1. Open **Picture library**.
2. Select your AI-generated images under **AI-generated pictures**, and authentic photos under **Real pictures**. You can select multiple files at once.
3. Add at least five pictures total. Include both categories for a more interesting game. Supported formats: JPG, PNG, WebP, GIF and AVIF.
4. Click **Done**, then **Let’s find out**. For a kiosk presentation, use the browser’s fullscreen option (usually F11).

The question is always **“Is this AI-generated?”** YES means AI-generated; NO means real. A correct answer earns one point, an incorrect answer earns zero. There are exactly five rounds, with five randomly selected pictures and no repeats within a game. Three, four or five points is a PASS; zero, one or two is a FAIL. Feedback appears after every answer. **Next participant** starts a new random game with a score of zero. Pictures may repeat between participants.

## Storage and practical notes

The picture database is stored in this browser’s IndexedDB, on this computer. Keep using the same browser profile and the same app folder. Moving the app, clearing browser data or using private browsing can make the saved library unavailable. Keep the original picture files as your backup. If browser storage is unavailable, the app explicitly reports that the library is temporary and works only while the tab remains open.

Import labels are the answer key; the app does not verify whether a picture was actually generated by AI. It does not collect names, save participant scores, or upload pictures. Filenames and category labels are hidden during the quiz. The library is an organizer convenience, not password protected.

The app includes seven organizer-supplied photographs, all labeled **Real** as instructed. They load automatically and are added to the browser database on opening the app. Reloading does not duplicate them, and removing a bundled photograph stays effective in that browser. The offline bundle preserves the original image bytes and loads even when browser storage is unavailable. Additional pictures can still be imported through **Picture library**.
